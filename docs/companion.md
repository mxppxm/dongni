# 敏的 BoopFace 形象

当前实现以 BoopFace 0.8.0 为运行时，自定义棕色马尾、绿色卫衣的小姑娘。使用同一张 SVG 绘制角色，眼睛形变、眨眼、视线跟随、等待动作、点头、按压和弹性拖拽实际由 BoopFace 驱动。

## 来源与边界

`vendor/boopface/` 来自 npm 官方包 `boopface@0.8.0`，通过 `npm pack --ignore-scripts` 获取。包内上游文件未修改，原版权和 MIT 许可保留在同目录的 `LICENSE`。来源：<https://github.com/CX-ArtLab/BoopFace>。

自定义绘制扩展位于 `components/minCharacter.js`，通过该版本的 `registerAvatarExtension` 接入绘制循环。它使用上游真实的眼睛节点与动作结果，增加虹膜、头发、卫衣、手臂、口型等外观；没有把原版机器人作为自创角色。因为扩展依赖上游内部节点和绘制钩子，升级版本时必须重新核对这些接口。

## 页面和状态

`/companion-preview` 提供可交互对照：左侧是敏，右侧是未经外观修改的原版 504「亮光黄」。同一组按钮切换两边的状态，可以直接比较表情和等待动作；鼠标移动、按住脸颊、拖动松开也可直接操作。

`Companion.tsx` 保留聊天和通话调用方的状态接口，将它们映射到 BoopFace：

| 应用状态 | BoopFace 动作 |
| --- | --- |
| 待机 | reset / 原生眨眼和视线跟随 |
| 输入 | inspect，保留人物眼睛的倾听式注视；原版对照仍使用 input 光标眼 |
| 等待回复 | startWaiting，wave |
| 后台干活 | startWaiting，spin；原版对照使用 wrap |
| 完成 | success |
| 等待回答 | wary |
| 倾听 | inspect |
| 回应 | 原生视线和眨眼，加自定义 SVG 口型 |

点击和键盘 Enter / 空格调用 affirm，并带动手臂打招呼。交互结束后，仍在输入或等待的状态会恢复；显示口型不代表逐音素对口型。角色使用 BoopFace 的可见性、自动睡眠和减少动态效果支持，自定义头发与手臂也遵循减少动态效果设置。

## 布局与降级

角色画布和文字区域独立，文字与画布间隔 28px，待机不常驻显示文字。移动端为角色留出独立一行，并增加消息底部留白，避免覆盖最后的消息和输入框。

上游代码通过客户端动态加载，组件卸载时移除实例，由 SDK 清理动画与手势监听。角色正常运行时不再使用头身贴图；旧角色 PNG 只用于代码尚未加载或加载失败时的兜底，原有历史素材和 mood 数据保留。
